# Day 01 — Language, Cognitive Science & Computational Linguistics

**Sessions covered:**
- Session 1: Language in Cognitive Science and NLP
- Session 2: Language Analysis and Computational Linguistics

## Session 1 Topics
- Definitions of Language (Sapir, Chomsky, Hockett's features)
- Natural vs Artificial Language, Ambiguity
- Linguistics as a Science, Levels of Analysis
- Three Generations of NLP (Rule-based → Statistical → Neural)
- **Textbook:** Bhattacharyya & Joshi, Ch. 1

## Session 2 Topics
- Syntagmatic vs Paradigmatic relations (Saussure, Firth)
- Levels: Phonetics → Morphology → Syntax → Semantics → Pragmatics → Discourse
- WordNet (synsets, hypernyms, meronyms)
- NLU, NLG, NLI architecture
- **Textbook:** Bhattacharyya & Joshi
